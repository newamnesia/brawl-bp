# 多邻国答题辅助（移动端原型）

这是与仓库里的荒野乱斗网页工具分开的原生移动端项目。它只翻译屏幕文字，不会替用户选择答案。

## Android

位置：`android/`。使用 Android Studio 打开，安装到 Android 8.0 或更高版本的真机。

1. 在首页选原文语言。目前支持英语、西班牙语、法语、德语、意大利语、葡萄牙语（拉丁字母 OCR）。
2. 点“启动悬浮翻译”，授予“显示在其他应用上层”和屏幕采集权限。Android 14 及更高版本每次新的采集会话需要系统确认。
3. 切到多邻国，点悬浮窗的“框选”，在冻结的屏幕画面上拖出包含文字的矩形；中文结果显示在同一悬浮窗。
4. 首次使用先联网下载源语言和中文翻译模型。之后 OCR 与翻译都在本机进行。

Android 原型在框选结束后计时，并在结果里显示处理毫秒数。超过 3 秒会明确显示超时状态，随后仍尝试完成翻译。**当前没有经过真机测试，不能声称 3 秒必达**。权限授权、模型下载和系统切换应用的时间不包含在处理计时内。

## iOS 画中画实验版

位置：`ios/`。需要 macOS、支持 iOS 26 的 Xcode、[XcodeGen](https://github.com/yonaskolb/XcodeGen)、开发者签名和 iOS 26 真机。在 `ios/` 执行 `xcodegen generate` 后打开生成的 Xcode 工程。将 `com.example...` 包名和 App Group 换成自己的签名标识，并在 Apple Developer 中创建对应 App Group。

1. 在主界面用四个滑块设定屏幕识别矩形。这是屏幕相对比例；切换到多邻国后，区域保持固定。
2. 等英语和简体中文离线语言包准备完成。
3. 启动画中画，再通过系统按钮开启屏幕广播并授权。翻译结果由画中画在其他应用上方显示。

iOS 采用 ReplayKit 广播扩展采集、Vision 识别、Translation 翻译、AVKit 画中画展示。ReplayKit 广播接口已被 Apple 标记为弃用；Apple 在 iOS 27 文档中推荐 ScreenCaptureKit。这个版本仅为技术验证，**尚未在 Xcode 或真机编译运行**，画中画后台更新、App Store 审核与 3 秒响应都未得到验证。系统画中画能否稳定承载翻译文字，需要真机测试；不能作为已交付的可靠产品宣称。

## 性能验收

- 先安装并预热语言模型，再测量“用户完成框选 / 屏幕内容变化 → 中文出现在悬浮窗”。
- 在目标机型上至少测 100 次不同长度的题目，记录 P50、P95、最大值与失败率。
- 只有在目标机型和目标语言的实测结果全部不超过 3 秒，才能对该组合承诺 3 秒。首次授权、模型下载、系统限制导致的黑屏或无法采集应单独报告。

## 系统限制

Android 应用若把窗口标记为不可截图，系统采集会得到黑画面。iOS 没有给第三方应用提供任意覆盖其他 App 的常规悬浮窗接口；这里的画中画是视频用途 API 的实验性复用，系统可关闭或限制它，也可能不符合 App Store 审核要求。
